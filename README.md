# ZephyrBeacon

A simple ZephyrBeacon server for event driven.

With ZephyrBeacon, you get a lightweight tool that stays out of your way.

**What you get**

- A simple ZephyrBeacon server for event driven

## Key Features

- A simple ZephyrBeacon server for event driven

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ZephyrBeacon.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ZephyrBeacon is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
